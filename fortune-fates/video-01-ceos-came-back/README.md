# Video 01: "Clocked Out. Clocked Back In." (30 CEO comebacks)

**Final video:** `out/FINAL_ceos_who_came_back.mp4` (1920×1080, 30 fps, ~2:23)
**Thumbnail:** `out/thumbnail.png` · **Title, description, credits:** `UPLOAD.md`

## The look: "the punch clock"
Being fired is *clocking out*; coming back is *clocking back in*.
- Every CEO is a paper employee time card with an HR photo paper-clipped on.
- Cards ride a steel rack, conveyor-style, under a time-clock machine.
- At the clock, each card is punched *ka-CHUNK*: the IN date prints, TIME AWAY appears, and a rubber stamp slams down with the **fate**.
- Stamp colour = outcome: green = won, red = disaster, blue = plot twist, black = neutral.
- The clock's flip display shows the comeback year, and a counter tallies how many are back in.
- Opening hook: an inter-office memo pinned to the wall. Ending: a 12-second hold on the last 3 cards, plus a marker scrawl, "Who did we miss?"
- Sound: original and code-generated. A D-minor pad, a ticking clock, a punch-clock "chunk" per card, and a stamp sound that matches the fate (bell, buzz, two-note twist).
- All textures (paper, wall, steel, stamp grunge) are generated by code. Fonts are free Google Fonts (OFL): Special Elite, Courier Prime, Anton, Permanent Marker.

Format rules taken from So Sánh Nhanh's top videos: no intro; one card every 4.5 s on a continuous scroll; cards in time order ending with the newest story; the title is "From [first card] to [last card]"; the thumbnail shows the first and last cards.

## Re-render (Python 3 + numpy + Pillow, Node + Playwright, ffmpeg)
```bash
python3 make_textures.py assets
node render.js stills 5,60,133
node render.js thumb
node render.js video 30
python3 make_audio.py out/timing.json out/audio.wav
ffmpeg -y -i out/video_noaudio.mp4 -i out/audio.wav -c:v copy -c:a aac -b:a 192k -shortest out/FINAL_ceos_who_came_back.mp4
```
- **Change a fact:** edit `cards.json` and re-render. Every field is plain text.
- **Change the pace:** edit `D` (seconds per card) at the top of the `<script>` in `scene.html`.
- **New photo:** save it as `photos/<photo field>.jpg` and add its license line to `photos/CREDITS.txt`.
- **Make video 02:** copy this folder, replace `cards.json`, and change the memo and tape text in `scene.html`.
